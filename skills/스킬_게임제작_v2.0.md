> 작업 유형: 브라우저 방치형 클리커 게임 제작 (단일 HTML)

---

## 📌 개요

단일 HTML 파일로 동작하는 방치형 클리커 게임 제작 스킬.
외부 라이브러리 없이 순수 HTML/CSS/JS만 사용.
v1~v8.2 제작 과정에서 축적된 모든 노하우를 담는다.

---

## ✅ 기본 원칙

1. **단일 파일 원칙**: 모든 스타일·스크립트를 하나의 HTML에 포함
2. **상태 중앙화**: 모든 게임 상태를 `S` 객체 하나에서 관리
3. **render 최적화**: 변경된 값만 DOM 업데이트 (PV 캐시 비교)
4. **localStorage 자동저장**: 10초마다 자동저장, 페이지 로드 시 불러오기
5. **계획 먼저**: UI 레이아웃 → 게임 루프 → 데이터 구조 순서로 설계
6. **GPU 우선**: 위치 이동은 `left/top` 대신 `transform: translate3d()` 사용
7. **파티클은 Canvas**: DOM 생성/삭제 반복 → Canvas 2D로 대체
8. **좌표는 캐싱**: `getBoundingClientRect()` 는 resize/노드수 변경 시에만 호출

## 🏗 게임 구조 템플릿

```
State (S 객체)
├── 자원         (money, inv, totalCollected, totalEarned, harvestLog...)
├── 업그레이드   (upg.price, upg.auto, upg.maxlv...)
├── 이벤트 상태  (fresh, wilt, angry, oxygenSat, oxyEvent...)
├── 유물         (relics.{key}.lv, relicPoints)
└── 노드/로봇    (nodes[], autoAcc)

Game Loop (requestAnimationFrame)
├── tickParticles(): Canvas 파티클 매 프레임 (60fps)
└── gameTick(dt):    게임 로직 100ms 단위 누적 처리
    ├── 노드 재생 체크
    ├── 이벤트 타이머 (중첩 방지 포함)
    ├── 자동채집 while 루프
    └── render() → 변경분만 DOM 업데이트

Save/Load
├── saveGame(): JSON → localStorage (10초마다)
└── loadGame(): localStorage → S 객체 + DOM 상태 동기화
```

### ① render 최적화 (PV 캐시)
```javascript
const PV = {};
function sc(id, val) {
  if (PV[id] === val) return;          // 변경 없으면 DOM 건드리지 않음
  const e = document.getElementById(id);
  if (e) e.textContent = val;
  PV[id] = val;
}
function sw(id, val) {                 // style.width 전용
  if (PV['w_'+id] === val) return;
  const e = document.getElementById(id);
  if (e) e.style.width = val;
  PV['w_'+id] = val;
}
```

### ② rAF 게임 루프 (파티클 60fps + 로직 100ms 분리)
```javascript
let lastTime = 0, accum = 0;
const TICK_MS = 100;
function loop(timestamp) {
  requestAnimationFrame(loop);
  tickParticles();                              // 매 프레임
  const dt = Math.min(timestamp - lastTime, 5000); // 탭 복귀 dt 폭주 방어
  lastTime = timestamp;
  accum += dt;
  if (accum >= TICK_MS) {
    const steps = Math.floor(accum / TICK_MS);
    accum -= steps * TICK_MS;
    gameTick(steps * TICK_MS / 1000);          // 초 단위로 전달
  }
}
```

### ③ autoAcc while 루프 (오프라인/탭 전환 보상)
```javascript
// ❌ 잘못된 방식 — 탭 전환 시 1번만 채집하고 나머지 증발
if (autoAcc >= ivl) { clickNode(); autoAcc = 0; }

// ✅ 올바른 방식 — 밀린 시간만큼 전부 처리
while (autoAcc >= ivl) {
  const avail = S.nodes.map((n,i) => n.available ? i : -1).filter(i => i >= 0);
  if (avail.length === 0) break;       // 캘 노드 없으면 중단 (무한루프 방지)
  clickNode(avail[Math.floor(Math.random() * avail.length)], true);
  autoAcc -= ivl;                      // %= 아닌 -= 로 자투리 정확 유지
}
```

```javascript
function effLv(key) {
  let lv = S.upg[key];
  if (S.relics.iron)      lv += S.relics.iron.lv;       // 아이언: 전체 +레벨
  if (S.relics.dimension) {
    if (key === 'nodes')  lv += [2,3,4][S.relics.dimension.lv - 1];
```

### ⑦ 확률 롤 안전장치 (부동소수점 오차 방어)
```javascript
function rollGrade() {
  // ... 확률 배열 pr 계산 ...
  // 합계 정규화 (부동소수점 오차 보정)
  const sum = pr.reduce((s, v) => s + v, 0);
  if (sum > 0 && Math.abs(sum - 100) > 0.0001) pr = pr.map(v => v / sum * 100);
  const r = Math.random() * 100; let cum = 0;
  for (let i = 0; i < pr.length; i++) { cum += pr[i]; if (r <= cum) return GK[i]; }
  // 오차 탈출 시 최고확률 등급 fallback
  let bestI = 0;
  for (let i = 1; i < pr.length; i++) { if (pr[i] > pr[bestI]) bestI = i; }
  return GK[bestI];
}
```

### ⑨ 노드 좌표 캐싱 (getBoundingClientRect 최소화)
```javascript
let nodeCache = [];
function cacheNodePositions() {
  const fr = document.getElementById('farm').getBoundingClientRect();
  nodeCache = S.nodes.map((_, i) => {
    const el = document.getElementById(`node-${i}`);
    if (!el) return { x: fr.width/2, y: fr.height*0.5 };
    const r = el.getBoundingClientRect();
    return { x: r.left - fr.left + r.width/2, y: r.top - fr.top + r.height/2 };
  });
}
// resize / 노드수 변경 시에만 호출
window.addEventListener('resize', cacheNodePositions);
// rebuildNodes() 완료 후: setTimeout(cacheNodePositions, 100);
```

### ⑩ Canvas 파티클 시스템 (DOM 생성 없음)
```javascript
const particles = [];
function spawnParticles(fx, fy, color, count) {
  for (let i = 0; i < count; i++) {
    const a = Math.random() * Math.PI * 2;
    const spd = 1.5 + Math.random() * 2.5;
    particles.push({ x: fx, y: fy,
      vx: Math.cos(a) * spd, vy: Math.sin(a) * spd - 1.5,
      r: 5 + Math.random() * 9, alpha: 1, color,
      life: 0, maxLife: 40 + Math.random() * 30 });
  }
}
function tickParticles() {
  ctx2d.clearRect(0, 0, canvas.width, canvas.height);
  for (let i = particles.length - 1; i >= 0; i--) {
    const p = particles[i];
    p.life++; p.x += p.vx; p.y += p.vy; p.vy += 0.06; // 중력
    p.alpha = 1 - p.life / p.maxLife;
    if (p.alpha <= 0) { particles.splice(i, 1); continue; }
    ctx2d.save(); ctx2d.globalAlpha = p.alpha;
    ctx2d.beginPath(); ctx2d.arc(p.x, p.y, p.r, 0, Math.PI * 2);
    ctx2d.fillStyle = p.color; ctx2d.fill(); ctx2d.restore();
  }
}
```

## ⚠️ 반복 실수 & 버그 패턴

| 버그/실수 | 원인 | 해결책 |
|---------|------|--------|
| autoAcc 탭 전환 증발 | `if` 조건 → 1번만 실행 후 리셋 | `while` 루프 + `acc -= ivl` |
| 확률 롤 fallback 오류 | 부동소수점 합계 >100 | 합계 정규화 + `r<=cum` + bestI fallback |
| 이벤트 중첩 소프트락 | angry/oxy 쿨타임 독립 작동 | `isAnyEventActive` 플래그로 일시정지 |
| dt 폭주 | 탭 복귀 시 timestamp 차이 무제한 | rAF 5000ms + gameTick 5.0s 이중 방어 |
| 리셋 후 모드 무한 지속 | `S=defS()`만으로 DOM 클래스 잔존 | `clearAllDOMState()` 명시적 호출 |
| 상점 업그레이드 불가 | 사이드/모달 잠금 오버레이 ID 중복 | `lkov-side-${key}` / `lkov-modal-${key}` 분리 |
| autoAcc 채집 미성공 리셋 | avail 없어도 리셋 | while 내부 `break` 후 감산 |
| render innerHTML 과도 사용 | 매 틱 DOM 재생성 | textContent + PV 캐시 |
| 자동채집 희귀 팝업 화면 가림 | 팝업 무분별 노출 | `isAuto` 플래그로 팝업/토스트 분기 |
| 노드 재빌드 시 상태 초기화 | 새 배열로 덮어씀 | `while (S.nodes.length < count) S.nodes.push(...)` |
| innerHTML 오타로 숫자 미표시 | 백틱 잔류 / 이중 할당 | 단일 할당으로 정리, 조심히 확인 |
| sed 1MB 문자열 치환 실패 | 쉘 인자 길이 한계 | Python 파일 처리로 대체 |
