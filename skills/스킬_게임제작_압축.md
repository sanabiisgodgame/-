# 스킬_게임제작_압축 (Quick Reference)

원본: `skills\스킬_게임제작_v2.0.md`

---

## 1) 작업 정의
- 브라우저 방치형/클리커 게임 제작
- **단일 HTML**(외부 라이브러리 없이 HTML/CSS/JS만)

---

## 2) 필수 구조(절대 권장)
- 상태 중앙화: 게임 상태는 `S` 객체 하나로 관리
- 렌더 최적화: PV 캐시(`sc/sw`)로 **변경된 값만** DOM 업데이트
- 저장/로드: localStorage 자동저장(예: 10초) + 로드 시 상태/DOM 동기화
- 게임 루프: `requestAnimationFrame` 기반, 파티클(60fps)과 로직(100ms)을 분리

---

## 3) 반드시 지킬 패턴(핵심)
- 오프라인/탭 전환 보상: `autoAcc`는 `if`가 아니라 **while**로 처리
- dt 폭주 방어: rAF dt 제한 + gameTick dt 제한 **2겹**
- 이벤트 중첩 방지: 한 이벤트가 활성이면 다른 이벤트 쿨타임을 멈추는 플래그 운영
- 이동/애니메이션: `left/top`보다 `transform: translate3d()` 우선(GPU)
- 파티클: DOM 생성/삭제 대신 Canvas 2D로 처리

---

## 4) 흔한 버그/주의사항
- 리셋 후 모드/클래스 잔존 → DOM 상태 명시 제거 함수 필요
- 잠금 오버레이 ID 중복 → 사이드/모달 ID 분리
- 확률 합계 오차 → 정규화 + fallback
- `innerHTML` 남발 → 성능/버그 유발(가급적 `textContent` + 캐시)
